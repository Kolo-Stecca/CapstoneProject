Capstone Project: Web-Based Project Management Dashboard
Description
This is a web-based project management dashboard designed to help manage clients, projects, tasks, time logs, and employee roles efficiently. The application aims to streamline project tracking, timekeeping, and reporting, while offering a user-friendly interface and secure, role-based access. It’s built using PHP, MySQL, and XAMPP, providing features such as real-time reporting, project/task management, and user authentication.

Features
Role-Based Authentication: Secure login system with different roles (Admin, Employee).

Project Management: Track projects, assign tasks, and manage project progress.

Time Tracking: Employees can log billable and non-billable hours.

Reports: Generate project progress reports, time logs, and task completion summaries.

Client Management: View and manage client information and associated projects.

Task Assignments: Assign tasks to employees and track their progress.

Technologies Used
PHP: For backend logic and server-side scripting.

MySQL: For database management.

XAMPP: Local server environment to develop and test the application.

CSS: For front-end styling and UI design.

Lucidchart: For database schema design.

MD5 Hashing: For temporary user password encryption (future implementation will replace with more secure hashing).
