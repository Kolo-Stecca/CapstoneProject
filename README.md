Capstone Project: Web-Based Project Management Dashboard
Description
This is a web-based project management dashboard designed to help manage clients, projects, tasks, time logs, and employee roles efficiently. The application aims to streamline project tracking, timekeeping, and reporting, while offering a user-friendly interface and secure, role-based access. It’s built using PHP, MySQL, and XAMPP, providing features such as real-time reporting, project/task management, and user authentication.
